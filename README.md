# Aplikasi Slip Gaji - SMP MU Boarding School

## Fitur
- Login multi-admin (superadmin + admin)
- 25 pegawai + kode unik selamanya
- Login guru pakai kode → logout = aplikasi tertutup
- Input gaji manual (multi-baris per pegawai)
- Import Excel otomatis (baris 15 & 32 tidak di-skip)
- Rekap + filter + export Excel
- Slip gaji multi-baris + download PDF/PNG
- Responsive di desktop, tablet, HP
- Tanpa notif WA & tanpa kolom TTD
